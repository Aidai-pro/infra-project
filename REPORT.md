Коммит — снимок проекта (сохранение). Staging area — черновик, куда выбираешь изменения перед сохранением.

Ветка — черновик проекта для безопасной разработки фичи отдельно от основного кода.

HEAD — метка «вы находитесь здесь».

git fetch — скачивает обновления с сервера. git pull — скачивает и сразу внедряет в твой код.

.env — хранит пароли и секреты; в репозитории их украдут.
